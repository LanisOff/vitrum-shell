# Wallpapers

The installer copies everything here into `~/Pictures/Wallpapers` (the folder
Settings → Wallpaper shows). A file you already have there under the same
name is left alone.

- **Images and videos** both work: jpg, png, webp, mp4, webm, mkv, gif.
- **`default.*`** is the wallpaper a fresh install starts with. Without one,
  the first image by name is used. An install that already has a wallpaper
  keeps it.
- **Day and night pairs** — `name-day.jpg` and `name-night.jpg` — switch
  when the scheme does, with automatic light and dark (Settings → Wallpaper →
  Day and night pictures).
